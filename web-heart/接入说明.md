# B2 首页交互爱心：接入说明

把 `b2-heart` 文件夹（b2-heart.js、three.module.min.js、heart.bin）放到网站根目录，然后在首页 hero 区域加：

```html
<section data-b2-heart style="position:relative;height:100vh;overflow:hidden">
  <!-- 原来的标题文字放在这里，加 style="position:relative;z-index:2;pointer-events:none" -->
</section>
<script type="module" src="b2-heart/b2-heart.js"></script>
```

交互：鼠标划过的胶囊会变蓝并弹起，2 秒后慢慢褪回米色；点地面会激起一圈波纹；鼠标放到爱心上，心跳会加快；点爱心，它会流下一滴蓝色眼泪，眼泪落地后周围胶囊晕成蓝色。手机上手指滑动也能触发。
性能：页面滚出屏幕后自动暂停；设备较慢时会自动降低分辨率；系统开启"减少动态效果"时会关闭地面波浪。
